# Лабораторная работа № 1. Процессы и каналы

Фомичев А. О., М8О-211БВ-25. Вариант 22 из 22, группа вариантов 5.

Родитель читает имена двух выходных файлов, затем строки произвольной длины.
Для каждой строки он случайно выбирает канал: с вероятностью 80% первый, с вероятностью 20% второй.
Каждый из двух дочерних процессов разворачивает полученные строки и выводит их в свой файл.
Оба процесса запускают одну программу `child`.

## Сборка и запуск

Linux или Ubuntu в WSL, компилятор C и GNU Make. Из корня репозитория:

```sh
cd lab1
make
./parent
```

Введите имя первого файла, нажмите Enter, затем имя второго и Enter.
Дальше вводите по одной строке. Для завершения нажмите Ctrl+D в начале пустой строки.
Имена должны указывать на разные файлы. При запуске содержимое существующих выходных файлов очищается.

Тот же пример одной командой, без ручного ввода:

```sh
printf '%s\n' first.txt second.txt Привет 'два слова' Linux 12345 | ./parent
cat -n first.txt
cat -n second.txt
```

В двух файлах вместе появятся четыре строки: `тевирП`, `аволс авд`, `xuniL`, `54321`.
В каждом файле сохраняется порядок попавших в него строк. Распределение при повторном запуске может измениться.
`printf` в этом примере — команда оболочки.

## Файлы и ввод

| Файл | Назначение |
| --- | --- |
| [parent.c](parent.c) | Открывает файлы, запускает два процесса, распределяет строки, ожидает завершения. |
| [child.c](child.c) | Читает строки из стандартного ввода и пишет результат в стандартный вывод. |
| [io.h](io.h), [io.c](io.c) | Динамический буфер строки, чтение блоками и полная запись. |
| [Makefile](Makefile) | Собирает программы `parent` и `child`. Запускайте `./parent` из каталога, где лежит `./child`. |
| [211_Fomichev_Lab1.pdf](211_Fomichev_Lab1.pdf) | Отчёт с листингом и протоколом проверок. |

Входной текст — UTF-8, единица разворота — кодовая точка Unicode. Например, `Я7A` превращается в `A7Я`.
Составной знак из нескольких кодовых точек тоже меняет их порядок. Родитель принимает LF и CRLF,
включая последнюю строку без перевода строки. На выходе каждая строка завершается LF. Пустая строка участвует в распределении.
Размер строки ограничен доступной памятью. Для строки длиной n байт разворот занимает O(n) времени и O(1)
дополнительной памяти сверх буфера строки. Диагностика выводится в stderr, при ошибке родитель возвращает код 1.
